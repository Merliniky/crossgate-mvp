以 Godot 重建经典开局的单机研究原型，使用原版角色、NPC、地图、UI 组件和音乐。保留国民任务与剑士就职的关键流程，触屏操作与单机规则重新实现。并非完整原版或恢复的服务器程序。

## 第一章怎么玩

1. 手机横屏打开网页，选择“创建角色”，分配 30 点初始能力。首次约需加载 131 MB 运行资源。
2. 与召唤士盖兹交谈，经回廊去灵堂，向测试者取得死者的戒指；返回盖兹处觐见国王。
3. 到里谢里雅堡二楼领取初宠与国民装备。在“物品”里装备衣鞋。
4. 去法兰东门近郊打哥布林、迷你蝙蝠；出售魔石赚钱，医院免费恢复人物和宠物。
5. 在东医院买止痛药交给安布伦，购买并装备平民剑，通过国营第 24 坑道及五层试炼洞窟取得推荐信，再到竞技场找迪索尔就职。
6. 完成国民任务、达到 5 级并就职见习剑士即可完成本章；之后仍可探索。

点击地面寻路，使用左侧方向键移动，点击 NPC 交谈。“地图”可以自动步行到出口或人物；“任务”查看下一步，“人物”升级加点，“系统”存读档。战斗中人物、宠物、敌人依次播放完整动作。

任务交付、换地图、战斗后自动保存。旧试玩存档可迁移；创建新角色前会保留一份旧存档备份，能在“系统”恢复。存档保存在当前设备和浏览器，清除网站数据会移除存档。
