# 魔力宝贝 · 手机单机 MVP

**[点击进入网页试玩](https://merliniky.github.io/crossgate-mvp/)**

**[安卓 APK 下载](https://merliniky.github.io/crossgate-mvp/CrossGate-MVP.apk)** · ARM64 / Android 7.0 以上 / v0.1.0 测试包

这是个人研究用途的单机原型，包含法兰城和芙蕾雅的地图小片段、原版角色及 UI 组件、音乐，以及重新实现的任务、战斗、宠物封印和本地存档。

## 手机试玩

1. 使用 Safari 或 Chrome 打开试玩链接，横屏使用。首次约需加载 67 MB 资源。
2. 点击地面行走，或使用屏幕左侧方向键；找“冒险者”接受委托。
3. 点击“前往野外”开始冒险，人物和宠物可分别选择行动，再执行回合。
4. 打败三只史莱姆后回城交任务；降低敌人生命后可尝试封印。
5. 使用“存档 / 读档”保存和恢复进度；存档保存在当前浏览器中。

首次操作后开启音乐，声音开关在“说明”窗口。不要在隐私浏览中保存长期进度；清除网站数据会移除浏览器存档。

## 版本范围

本仓库存放可直接托管的 Godot Web 导出产物和安卓测试包。游戏程序使用 Godot 4.6.1，Android 无联网权限。网页版需要支持 WebGL 2 的浏览器。

战斗数值、任务及捕捉规则为简化的本地实现，并非完整原版或恢复的服务器程序。已完成逻辑、场景和导出资源检查，尚未进行手机真机测试。
